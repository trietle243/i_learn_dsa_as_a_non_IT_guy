# DSA Playground

Learning Data Structures & Algorithms
with Python and Go.

## Philosophy
One problem, two implementations.

1. Understand the problem
2. Solve it in Python
3. Rewrite it in Go
4. Test both
5. Analyze complexity
6. Document what I learned

## Commands

    make setup
    make test
    make test-py
    make test-go
